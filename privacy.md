  ## Suomeksi

  **Mitä tietoja kerätään?**

  Tutka ei kerää, tallenna eikä lähetä henkilötietoja.

  - **Sijaintitieto** — käytetään ainoastaan tutkanäkymän keskipisteen laskemiseen
    laitteella. Sijaintiasi ei tallenneta eikä lähetetä mihinkään palvelimelle.
  - **API-tunnukset** (OpenSky Network, Finavia) — tallennetaan ainoastaan laitteellesi
    Androidin Keystoreen. Niitä ei lähetetä muualle kuin kyseisten palveluiden omiin
    rajapintoihin.

  **Kolmannen osapuolen palvelut**

  Sovellus hakee dataa seuraavilta julkisilta palveluilta käyttäjän laitteen nimissä:

  - OpenSky Network (opensky-network.org) — lentokoneiden sijaintitiedot
  - Digitraffic / Fintraffic (digitraffic.fi) — alusten AIS-data
  - Finavia API (finavia.fi) — lentoasemien reittitiedot (valinnainen)
  - adsbdb.com — lentojen reittitiedot (valinnainen)
  - MapTiler (maptiler.com) — karttatiilet

  Näiden palveluiden omia tietosuojakäytäntöjä sovelletaan heidän tietoihinsa.

  ## In English

  **What data is collected?**

  Tutka does not collect, store, or transmit personal data.

  - **Location** — used only on-device to calculate the radar centre point.
    Your location is never stored or sent to any server.
  - **API credentials** (OpenSky Network, Finavia) — stored only on your device
    in Android Keystore. Sent only to the respective service APIs.

  **Third-party services**

  The app fetches data from the following public services on behalf of the user's device:

  - OpenSky Network — aircraft positions
  - Digitraffic / Fintraffic — vessel AIS data
  - Finavia API — airport flight data (optional)
  - adsbdb.com — flight route data (optional)
  - MapTiler — map tiles

  Their own privacy policies apply to their respective data.
